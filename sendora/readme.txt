Connect WordPress to Sendora using a server-side API key.

== Description ==

This initial release provides the Sendora plugin foundation, API client, and
an administrator-only settings page with a secure connection test.

== Manual connection check ==

1. Open WordPress admin and choose Sendora.
2. Save an HTTPS API base URL and an API key beginning with sk_.
3. Confirm that only the final four API key characters are displayed.
4. Select Test connection.
5. Confirm that a successful test is green and a failed test is red.
